# Simulated multimodal milling dataset

This folder holds the **training dataset the models actually use**.

It is **not** a public PHM download and **not** laboratory profilometer data.
It is generated by the physics-inspired Al 6061 end-milling simulator in
`src/acquisition/simulator.py` and written by `AdvancedMonitor.train()`.

## File

| File | Contents |
|---|---|
| `simulated_milling_dataset.csv` | One row = one 0.25 s window |
| `training_metrics.txt` | Held-out MAE / AUC (simulated test split only) |

Regenerate:

```
python scripts/train_monitor.py
```

## What the dataset focuses on

**Process window (Al 6061, 10 mm, 4-flute end mill)**

- Spindle speed: 2400 / 2700 / 3000 / 3300 / 3600 r/min
- Feed per tooth: 0.08 / 0.10 / 0.12 / 0.14 / 0.16 / 0.18 mm/tooth
- Axial depth: 1.0 mm
- Ra specification: 1.6 µm
- Flank-wear demo limit: 0.30 mm (ISO 8688-style)

**Signals inside each window (2 kHz during training, 5 kHz on the live dashboard)**

- Vibration (accelerometer-like)
- Cutting force
- Spindle power / current
- Temperature
- Commanded rpm and feed

**Labels (simulator ground truth)**

- `label_ra_um` — arithmetic roughness Ra
- `label_vb_mm` — flank wear land VB
- `label_wear_rate_um_s` — dVB/dt
- `label_rul_s` — remaining time until VB = 0.30 mm
- `label_degrade_in_horizon` — 1 if Ra or VB will cross the limit inside 30 s

## What the models calculate from it

See the project summary in the chat / README. In short: 16 engineered features,
GMM regimes A–D, HGB heads for Ra / VB / wear rate / temperature / RUL / 30 s
risk, Isolation Forest anomaly score, physics residual \(P \approx P_{idle}+F_c V_c\),
MRR and specific cutting energy.
